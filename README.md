# DIGITAL LITERACY I — SS 2026

Eine historische Untersuchung von Maker- und Hackerspaces mit interaktivem **Voting Wheel**.

## Live-Demo

**https://syl4r313-lab.github.io/DigLit1/**

## Lokal starten

```bash
npm install
npm run dev
```

Dann unter `http://localhost:3000` erreichbar.

## Deployment

Automatisch via GitHub Actions auf GitHub Pages bei jedem Push auf `main`.

**Einmalige Einrichtung:** GitHub → Settings → Pages → Source: **GitHub Actions**
